# AC — айдентика

| Файл | Что это |
|---|---|
| `ac-logo.svg` | Основной логотип: тёмно-синий `#163A63`, звезда с золотым градиентом |
| `ac-logo-flat.svg` | Плоская версия, звезда одним цветом `#C9A35A` (для печати, вышивки, мелких размеров) |
| `ac-logo-white.svg` | Белая версия для тёмного и синего фона |
| `ac-logo.png` | Логотип 2336×1448, прозрачный фон |
| `ac-pattern.svg` / `.png` | Паттерн 1250×1250 (PNG 2500×2500), прозрачный фон |
| `ac-pattern-tile.svg` / `.png` | Бесшовный тайл 720×548 для заливки любых площадей |

Все SVG без растровых вставок и внешних шрифтов. Просветы между буквами и вокруг звезды сделаны масками,
поэтому логотип и паттерн корректно ложатся на любой фон.

Цвета паттерна: буквы `#C8DCF6`, звёзды `#C4A15F` (часть звёзд в цвет букв, как на референсе).

`generate.py` пересобирает все SVG: `python3 generate.py .`
