# Map by Map — анимированная обложка / интро канала (8 с, 16:9)

`out/map-by-map-intro.mp4`: 1920×1080, 60 fps, H.264, звук AAC. План сцен описан в `STORYBOARD.md`.

**Части обложки.** `split.py` разбирает `cover.jpg` на части (`parts/*.png` и `parts.json`):
- материки и острова по отдельности;
- бирюзовый и оранжевый ободки (выделены полярной развёрткой от края шара);
- разделитель;
- Антарктида.

Альфа считается по проекции цвета на ось «фон → цвет слоя», поэтому сглаженные края сохраняются. Собранные части совпадают с исходником.

**Анимация.** `scene.js` — Canvas 2D с функцией `seek(t)`:
- **0–3 с:** сборка «карта за картой» на восьмые доли (120 BPM), разрез, Антарктида;
- **3–4 с:** шар уходит влево, появляется орбита;
- **4–8 с:** название «MAP / by / MAP». Последнее слово раскрашено по диагонали, как глобус.

Звук (`audio.js`) синтезируется Web Audio.

**Сборка:**
```
python3 split.py
for i in 0 1 2 3; do node render.mjs $i 4 & done; wait; node join.mjs
```
Для `split.py` нужны numpy, scipy и Pillow. Рендер использует Playwright из `../cocktails/node_modules`.
