# Правила серии (motion-ai) — держать во всех следующих выпусках

- Формат: 1080×1920, 9:16, 60 fps. Сначала макеты, после одобрения рендер.
- Один непрерывный 3D-глобус без склеек и плоских карт; перелёты 2–3 с (отдаление → дуга → приближение).
- Начало: первые ~2 с Земля вращается при неподвижной камере, затем приближение. Финал петлёй к вращающейся Земле.
- Призыв подписаться — «Follow» (ролики идут в YouTube, TikTok, Instagram), кнопка в цвете серии #2F7BF5 без логотипов площадок.
- **Countryball смотрит в сторону страны:** страна сверху — взгляд вверх; справа — вправо; слева — влево; снизу — вниз. Пока зритель думает — на страну; на ответе и призывах — на зрителя.
- Субтитры и анимации синхронизируются по реальному голосу (выравнивание по паузам).
