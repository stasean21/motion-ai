# 22 промпта для фото (разные предметы, пары «до → после»)

**Общие правила**
- Формат: вертикальный 4:5 (1024×1280 или больше). Предмет по центру, занимает около 60–70% ширины кадра.
- Порядок: сначала **BEFORE**. Потом **AFTER**, прикрепив BEFORE как референс и начав промпт с фразы:
  `Use the attached image as reference: keep the exact same object, same design, same colors, same position and size in frame.`
- Без логотипов, брендов, текста и водяных знаков. Имена файлов: `00a.png`, `00b.png`, `01a.png`, `01b.png` … `10b.png`.
