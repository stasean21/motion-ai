# «Товар готов. А документы?» — раскадровка

9:16 · 1080×1920 · 60 fps · 37 с · без голоса (голос подставляется в монтаже), фоновый гул + звуки интерфейса.

**Единая нить.** Одна и та же карточка товара проходит путь от «готов к продаже» до «документ действует».
Один и тот же документ постоянно превращается: уведомление → карточка сертификации → две карточки
(сертификат / декларация) → протокол → документ → строка реестра → переписка → призыв.
Каждое превращение — это и есть переход между сценами (принцип рефа: виджет iOS буквально иллюстрирует фразу).

**Стиль из рефа.** Пастельный mesh-фон меняет цвет под сцену, белые объёмные карточки iOS, Inter Display Heavy,
субтитры-караоке: строка видна целиком размытым «призраком», слова проявляются из размытия по таймингу речи,
ключевое слово — цвет сцены + эллипс «от руки» + искры. Переходы — гигантское слово с размытием движения
и смена через размытие + белые глитч-штрихи. Плашка внизу постоянна.

**Факты.** В ролике нет номеров регламентов, названий схем и конкретных сроков. Номера в реестре скрыты точками.
Текст не утверждает, что документ обязателен для каждого товара: «если подтверждение обязательно…».
