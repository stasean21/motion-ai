Все числа — условный учебный пример, без символов валюты.

## Визуальные правила (перенесены из «Send a photo»)
- Светлый фон (по брифу тёплый: #F7F3EC с мягкими кремовыми, персиковыми и мятными пятнами).
- Плитки и карточки — Liquid Glass. Все объекты ровные, без наклона и ракурса.
- Субтитров нет, только крупные надписи из сценария (Inter Display Black). Композиция по всей высоте и ширине.
- **Бирюзовый #14B8A6 = темп инфляции (снижается). Оранжевый #FF6A00 = цены (растут).** Цвет несёт смысл во всём ролике.
- Продукты и объекты простые, объёмные, с мягкими тенями, без мелких деталей.

## Сквозная нить
Один объект «тянет» другой. Заголовок в телефоне → чек → корзина → ценник → число → график → дорога → колесо → снова ценник → две корзины → чек → телефон.
Каждая смена сцены — это **превращение предмета** и **кинетический жест** (резкий разгон и торможение, размытие движения, кинетическая типографика). Простых растворений нет.

## Кинетические приёмы (общий словарь)
- **Kinetic type:** слова надписей влетают по одному с переразгоном и микроотскоком. Цифры пересчитываются «барабаном» (rolling digits).
  Проценты морфятся (10 → 2): цифра сжимается по ширине, меняется и разжимается.
- **Whip / smear:** короткий разгон камеры (6–8 кадров) с направленным размытием, как у гигантских слов в прошлых роликах.
- **Match-cut по форме:** круг → круг, линия → линия (значок корзины → корзина, ценник → карточка «100», линия графика → дорога,
  бейдж +2% → спидометр, колесо → отверстие ценника, чек → чек).
- **Squash & stretch** у ценника и чека (бумага тянется и пружинит).

## Звук

Без вокала и финального аккорда. Звуки — по событиям из сценария (сигнал новости, бумага, глухой удар, появление продуктов,
спад тона, щелчки значений, цифровой перелив, движение машины, свист).
