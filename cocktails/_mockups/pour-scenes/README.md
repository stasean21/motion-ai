# Фотомакеты сцен · Margarita на присланных кадрах

Только кадры, не ролик. Исходные кадры — `../../06-margarita-photo/assets/shots/` (одна сцена, свет и ракурс как на исходном фото).

| Файл | Сцена | Что сделано |
|---|---|---|
| `out/01-glass-in.jpg` | бокал въезжает | бокал с солью вырезан по силуэту и сдвинут вправо со смазом движения, отражение на стойке тянется за ним |
| `out/02-tequila.jpg` | текила в шейкер | бутылка вырезана и наклонена, прозрачная струя с губы горлышка: перевёрнутый фон, яркие края |
| `out/02b-liqueur.jpg` | ликёр в шейкер | янтарная струя светится на просвет |
| `out/02c-lime-juice.jpg` | лаймовый сок в шейкер | мутная жёлтая струя |
| `out/03-shake.jpg` | шейк | шейкер в воздухе, наклон и смаз, конденсат на металле, капли со шва крышки |
| `out/04-strain.jpg` | в бокал | пустой бокал наполнен наполовину жидкостью с исходного фото, мутная струя из шейкера, пена, корона, пузырьки |
| `out/05-lime-wheel.jpg` | лайм | полный бокал, долька падает на ободок |
| `out/sheet.jpg` | все кадры рядом | |

Главный приём — `fill_coupe` в `lib.py`: пустой бокал наполняется настоящей текстурой напитка с исходного фото (пузырьки, пена, мутность) до любого уровня, блики стекла и соль остаются поверх. В ролике уровень может расти плавно.

Сборка: `python3 -I scenes.py` (все) или `python3 -I scenes.py 04` (одна сцена). Нужны numpy, pillow, opencv-python-headless и `assets/plate.png` (`../../_tools/clean_frame.py`).
