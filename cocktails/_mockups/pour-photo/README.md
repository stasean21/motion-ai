# Фотомакет · струя в бокал (фото Margarita)

Один кадр: в бокал с фото `06-margarita-photo/assets/source.png` льётся мутная лаймовая струя.

- `pour.jpg` — кадр 1080×1920.
- `pour-detail.jpg` — крупно место падения.
- `pour.py` — как собран: считается в 2× на фото без рамки, рамка с исходника кладётся сверху.

Что в кадре:
- **Струя:** падает по параболе и сужается книзу, по ней идёт рябь. Тело мутное лаймовое, сквозь него просвечивает перевёрнутый фон. Видны продольные струйки, тёплый блик от лампы слева, тёмная кромка по краю.
- **Место падения:** круги и пена на поверхности, корона брызг, капли.
- **Под поверхностью:** облако пузырьков, видно через стекло.

Сборка: `python3 -I pour.py` (нужны numpy, pillow, opencv-python-headless и `assets/plate.png` из `../../_tools/clean_frame.py`).
