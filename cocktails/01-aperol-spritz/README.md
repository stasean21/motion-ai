## Стиль

Ар-деко, барное меню 1920-х. Фон — винный бархат с золотой рамкой и веером. Бокал — с фото (`assets/`, исходник в `../_assets/glass-wine/`).
Бутылки без брендов: игристое (зелёная, золотая фольга), аперитив (прозрачная с оранжевым), содовая (голубоватая, крышка).
Шрифты: Poiret One (цифры и подписи), Great Vibes (названия).
