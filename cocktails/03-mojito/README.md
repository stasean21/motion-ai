Формула 50 · 20 · 100. Бокал хайбол.

## Стиль

Серия: ар-деко, винный бархат, золотая рамка, Poiret One + Great Vibes, плавная камера.
Акцент — мятный `#8DD67E`. Хайбол нарисован кодом. Дроблёный лёд — ~130 кусочков, сыплются рядами снизу вверх; в зоне льда жидкости 55 % сечения, уровень считается по объёму.
Листья мяты падают на дно, темнеют после мадлера и поднимаются между льдом после содовой. Газ идёт до конца ролика.
Бутылки без брендов: сироп (маленькая, пробка), ром (прозрачная, квадратные плечи), содовая.
