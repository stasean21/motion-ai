# 06 · Margarita · photo (EN)

16 s · 120 BPM · 1080×1920 · 60 fps · анимация готового фото.

Исходник — фото маргариты на винном бархате с золотой рамкой (`assets/source.png`). В этом ролике фото само становится сценой, бокал заново не рисуется.

## Что движется

| Слой | Движение |
|---|---|
| Камера | плавный наезд и отъезд за 16 с, параллакс по карте глубины: штора, лампа, бокал и стойка сдвигаются на разную величину |
| Штора | бархат колышется, внизу сильнее, чем у карниза; по складкам скользит свет |
| Напиток | лёгкая дрожь под пеной, каустика, поднимаются пузырьки |
| Стекло | блик проходит по чаше, ножке и лайму на 2.2 с и 10.2 с |
| Соль | искры по одной на кристаллах ободка и на рассыпанной соли (точки найдены на фото, `assets/sparkles.js`) |
| Лампа | мерцает, отражение на стойке мерцает вместе с ней |
| Рамка и веер | сняты с фото и нарисованы отдельным неподвижным слоем: в начале прорисовываются от веера, по ним бежит блеск |
| Боке | тёплые и лаймовые пятна на переднем плане, двигаются быстрее сцены |

## Текст (версия с текстом)

| Время | Что на экране |
|---|---|
| 0.9–5.3 с | COCKTAIL · *Margarita* (появляется слева направо) · THE MEXICAN CLASSIC |
| 5.6–10.1 с | YOU WILL NEED: 50 ml tequila, 25 ml orange liqueur, 25 ml lime juice + salt, ice, lime wheel |
| 10.4–13.5 с | REMEMBER THE RATIO 2 : 1 : 1 с полосами |
| 13.7–16 с | *Save this recipe* · PLEASE DRINK RESPONSIBLY |

## Файлы

- `out/margarita-photo.mp4` — с текстом, музыкой и звуками, затемнение в начале и в конце.
- `out/margarita-photo-loop.mp4` — без текста, бесшовный цикл: все движения и музыка повторяются каждые 16 с.
- `out/storyboard.jpg`, `out/storyboard-clean.jpg` — кадр каждые 0.5 с.

## Как собрать

```
python3 ../_tools/clean_frame.py assets/source.png assets/plate.png   # фото без рамки (нужен opencv-python-headless)
python3 ../_tools/make_plate_js.py                                    # assets/plate.js и assets/sparkles.js
node beats.mjs                              # раскадровка
node beats.mjs 0.25 clean
node render.mjs margarita-photo             # версия с текстом
node render.mjs margarita-photo-loop clean  # чистый цикл
```

Чтобы анимировать другое фото, поменяйте в `scene.js` координаты бокала, лайма и стойки (функции `bowl`, `lime`, `stem`, `foot`, `edge` в шейдере, в пикселях исходника) и пересоберите `plate.js` и `sparkles.js`.
