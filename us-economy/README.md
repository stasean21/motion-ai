# Episode 04 — Can 50 Countries Match the US Economy? (EN)

`anim/out/us-economy.mp4`: 1920×1080, **30 fps**, как в брифе; H.264 + AAC, 8:21 (501 с).

**Стиль «смесь».** От прежних выпусков — тёмная карта и наш интерфейс: шкала, карточка, счётчики, мини-карта. Новое:
- страны залиты своими флагами;
- у стран мультяшные глаза: США следят за текущей страной, страны команды смотрят на США;
- эмоции по сюжету: на Франции США насторожены, на пересечении цели шок, команда радуется.

**Музыка — демо по референсу** (110 BPM, ля минор, F–G–Am–G). Секции меняются на 10%, 25% и 50%, к Франции идёт нарастание, под разрывом у Великобритании ударные уходят, на Германии музыка разрешается. В окнах реплик диктора она приглушена.

**Устройство (`anim/steps.js`).** Шаблоны шага разной длины:
- 8 с — страны 1–40;
- 12 с — страны 41–47;
- 20 с — Франция и Великобритания, рост шкалы линейный 8 с;
- 16 с — Германия: цель пересекается на 49.1% сложения.

Кадр камеры каждой страны считается автоматически по её основной части (`MAINBOX` в `build-map.mjs`). Крошечные страны показаны в лупе-вставке. На 10/20/25/30/35/40 странах и на Франции появляются обзоры командной сетки флагов. Вехи по брифу: 1/5/10/25/50/75/100%, плюс $1T, $10T и $20T.

**Данные** — из брифа (World Bank WDI, 2025). Суммы и проценты взяты как в брифе.

**Рендер:**
```
node build-map.mjs
cd anim && DUR=501 FPS=30 NAME=us-economy sh -c 'node audio.mjs sfx & node audio.mjs music & for i in 0 1 2 3; do node render.mjs $i 4 & done; wait; node join.mjs'
```
