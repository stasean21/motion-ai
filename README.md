## Страница

`docs/index.html` — готовый статический сайт. Плеер запускается со звуком после нажатия «Смотреть со звуком».
На странице: семь сцен с переходом к нужному времени, обложка, контактный лист, шесть исходных карточек,
отдельная аудиодорожка и скачивание файлов. Верстка адаптирована для телефона.

Для GitHub Pages в настройках репозитория выберите Settings → Pages → Deploy from a branch → main → /docs.
Все изображения, аудио и видео локальны, внешних шрифтов и сервисов не требуется.

## Проверено

1080×1440, 30 fps, 450 кадров, 15,000 секунд, H.264 yuv420p, AAC 48 кГц, стерео.
В браузере проверены воспроизведение с ненулевым аудиосигналом, управление громкостью,
переходы по сценам, повтор, увеличение изображений, скачивание и мобильная верстка.

Сделано по скиллу PROF AI Motion.
