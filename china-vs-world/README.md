# Episode 02 — How Many Countries Does It Take to Match China’s Population? (EN)

`anim/out/china-vs-world.mp4`: 1920×1080, 60 fps, H.264, AAC, 5:50. Ролик собран на движке выпуска про Индию. Музыка и эффекты тише, чтобы сверху лёг голос. Текст диктора — в `VOICEOVER.md`, материалы для YouTube — в `youtube.md`.

**Устройство:**
- **Вступление 0:00–0:30** (`anim/scene.js`): Китай загорается, вокруг появляются безымянные карточки «?», затем вопрос «25 COUNTRIES vs CHINA?», счётчик 1,416.1M, правила.
- **Шаги стран** (`anim/steps.js`): 10 с на страну, у последних пяти по 20 с.
- **Особые моменты:** всплывающие отметки 1%/100M…1B, вспышки 25/50/75/100% в момент пересечения, сравнения на Германии и Японии, «STILL SHORT» и GAP на Нигерии, колпачок +0.8% на Филиппинах, финал с местом под конечную заставку.
- **Мини-карта** слева вверху держит Китай в кадре во время наездов.

**Данные.** Население и суммы взяты из брифа (UN WPP 2024, 2025). Проценты тоже взяты из брифа: они посчитаны по точным значениям, а не по округлённым. Тайвань, Гонконг, Макао и Западная Сахара — отдельные объекты карты, к Китаю и Марокко не добавляются.

**Рендер:**
```
node build-map.mjs   # → map-data.js
cd anim && DUR=350 NAME=china-vs-world sh -c 'for i in 0 1 2 3; do node render.mjs $i 4 & done; wait; node join.mjs'
```
Полный ролик больше 100 МБ и в git не хранится.
