# How many countries does it take to match India? — макет кадров (EN)

Версия для англоязычной аудитории: все надписи на экране и текст диктора на английском, числа в формате `1,463.9M`.

16:9 · 5:40 · анимированная карта, флаги, счётчик, короткие комментарии. **Пока только макет: 3 ключевых кадра.**

| Кадр | Тайм-код | Что показывает |
|---|---|---|
| `frames/1.png` | 0:06 | Цель: Индия оранжевая со свечением, счётчик 1,463.9 million people |
| `frames/2.png` | ~1:50 | 10 стран (Чили): две полосы на одной шкале, ряд из 10 флагов, «…and that’s just over 7%» |
| `frames/3.png` | ~4:25 | 25 стран (США): шкала встаёт на 99.6%, лупа на зазоре «About 5.7M to go» |

`board.jpg` — все кадры с подписями: камера, действие, voiceover.

**Интерфейс на каждом кадре:**
- слева сверху «Added: NN»;
- справа сверху «India — 1,463.9M» (не исчезает при зуме);
- справа карточка страны: флаг, номер, название, население;
- внизу шкала относительно Индии с отметками 25/50/75% и целью (GOAL).

**Данные:** оценки за 2025 год (UN WPP 2024 / StatisticsTimes.com) из брифа, список `LIST` в `frames.js`.

**Карта:** Natural Earth 50m (`world-atlas`), проекция Natural Earth 1. Флаги взяты из `flag-icons` (MIT).

**Сборка:**
```
npm i && node build-map.mjs   # → map-data.js
node shot.mjs                 # → frames/*.png, board.png
```
