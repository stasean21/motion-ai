# Сколько стран нужно, чтобы сравняться с Индией по населению? — макет кадров

16:9 · 5:40 · анимированная карта, флаги, счётчик, короткие комментарии. **Пока только макет: 3 ключевых кадра.**

| Кадр | Тайм-код | Что показывает |
|---|---|---|
| `frames/1.png` | 0:06 | Цель: Индия оранжевая со свечением, счётчик 1 463,9 млн |
| `frames/2.png` | ~1:50 | 10 стран (Чили): две полосы на одной шкале, ряд из 10 флагов, «чуть больше 7%» |
| `frames/3.png` | ~4:25 | 25 стран (США): шкала встаёт на 99,6%, лупа на зазоре «осталось около 5,7 млн» |

`board.jpg` — все кадры с подписями: камера, действие, диктор.

**Интерфейс на каждом кадре:**
- слева сверху «Добавлено: NN»;
- справа сверху «Индия — 1 463,9 млн» (не исчезает при зуме);
- справа карточка страны: флаг, номер, название, население;
- внизу шкала относительно Индии с отметками 25/50/75% и целью.

**Данные:** оценки за 2025 год (UN WPP 2024 / StatisticsTimes.com) из брифа, список `LIST` в `frames.js`.

**Карта:** Natural Earth 50m (`world-atlas`), проекция Natural Earth 1. Флаги взяты из `flag-icons` (MIT).

**Сборка:**
```
npm i && node build-map.mjs   # → map-data.js
node shot.mjs                 # → frames/*.png, board.png
```
